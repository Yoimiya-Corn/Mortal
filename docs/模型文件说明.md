# 如何获取 Mortal 模型文件

> **重要提示**: Mortal 的代码是完全开源的,但官方并未公开发布模型权重文件。

## 快速链接

📖 **完整文档**: 请查看 [MODEL_WEIGHTS.md](MODEL_WEIGHTS.md) 获取详细信息

🌐 **英文文档**: 请查看 [src/user/model_weights.md](src/user/model_weights.md)

## 简要说明

### 现状

根据项目维护者 Equim-chan 的说明:
- ✅ **源代码**: 完全开源,可在 GitHub 获取
- ✅ **libriichi 库**: 可从 [shinkuan/Mortal_v4](https://github.com/shinkuan/Mortal_v4/releases) 下载
- ❌ **模型权重**: 官方未公开发布

### 获取模型的方式

1. **查看官方 Gist 帖子**
   - README 中引用的帖子: https://gist.github.com/Equim-chan/cf3f01735d5d98f1e7be02e94b288c56
   - 可能包含获取模型的相关说明

2. **自行训练模型**
   - 按照[构建文档](https://mortal.ekyu.moe/user/build.html)配置环境
   - 准备训练数据集(需要大量麻将对局记录)
   - 使用 GPU 进行训练

3. **使用在线服务**
   - Mortal 提供在线服务接口,无需本地模型
   - 详见[在线服务文档](https://mortal.ekyu.moe/online/index.html)

### 相关资源

# 本地跑谱网站使用指南

## 📋 目录结构

```
web_app/
├── app.py                      # Flask 后端服务器
├── requirements.txt            # Python 依赖
├── README.md                   # 完整文档
├── templates/
│   └── index.html             # 网页界面
└── static/
    ├── css/
    │   └── style.css          # 样式文件
    └── js/
        └── app.js             # 前端逻辑
```

## 🎯 核心功能

### 1. 模型加载
- 输入模型路径: `D:\vscode\Mortal\model\Corn.pth`
- 支持在命令行或网页中加载
- 显示模型标签和状态

### 2. 牌谱分析
- 支持 mjai 格式
- 选择玩家视角 (0-3)
- 实时分析每一巡

### 3. 结果展示
- 事件列表
- AI 建议
- Q 值可视化
- 决策元数据

## 📡 API 接口

### 1. 检查状态
```bash
GET /api/status
```

### 2. 加载模型
```bash
POST /api/load_model
Body: {"model_path": "D:\\vscode\\Mortal\\model\\Corn.pth"}
```

### 3. 分析牌谱
```bash
POST /api/analyze
Body: {
  "mjai_log": "...",
  "player_id": 0
}
```

## 🔧 启动方式

### 方式 1: 预加载模型
```bash
cd web_app
python app.py --model "D:\vscode\Mortal\model\Corn.pth"
```

### 方式 2: 网页加载
```bash
cd web_app
python app.py
# 在浏览器中输入模型路径并加载
```

### 方式 3: 自定义端口
```bash
python app.py --model "D:\vscode\Mortal\model\Corn.pth" --port 8080
```

## ⚙️ 配置说明

### 系统要求
- Python 3.9+
- PyTorch
- Mortal 依赖
- Flask 2.3+

### 文件路径
Windows 路径使用反斜杠或双反斜杠：
- ✅ `D:\vscode\Mortal\model\Corn.pth`
- ✅ `D:\\vscode\\Mortal\\model\\Corn.pth`

## 🐛 常见问题

### Q: 模型加载失败
A: 检查路径是否正确，文件是否存在

### Q: 分析失败
A: 确保 mjai 格式正确，每行一个 JSON 对象

### Q: 端口被占用
A: 使用 `--port` 参数指定其他端口
